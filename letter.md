Репозиторий: https://github.com/Dontgoingforyou/ai-helper

Сделан локальный прототип. На вход подаётся JSON прибора, на выход — черновик карточки в Markdown и JSON: заголовок до 70 символов, описание 800–1 200, характеристики, 3–5 поисковых запросов и короткий блок для менеджера. Пустое значение характеристики записывается как «данных нет».

Модель вызывается через OpenAI-совместимый API. По умолчанию Groq и openai/gpt-oss-120b: с этой машины OpenAI и Google AI Studio не открываются. Ключ лежит только в `.env`. Характеристики копируются из входа. Описание и блок для менеджера собираются из фраз паспорта и строк характеристик, без пересказа модели. Если во входе два разных числа об одном свойстве, остаются оба. Если модель дважды не вернула JSON, карточка собирается из входных полей. Повтор запроса есть только при таймауте, обрыве сети и статусах 429, 500, 502, 503, 504.

Модель часто отвечает рассуждением без JSON или не попадает в длину. На странице CEM DT-8890А в тексте указано 60 кПа, в таблице — 137,9 кПа; оба числа сохранены. Текст паспорта короче требуемых 800–1 200 символов, поэтому известные фразы повторяются, а не дополняются новыми фактами. На бесплатном Groq живой запуск упирается в лимит запросов.

Дальше можно убрать повтор фраз, не теряя длины, и собирать JSON из каталога без ручных фикстур. Веб-форма, база и деплой в это задание не входили.
